## 1. Двойственная задача

[cite_start]Для любой задачи линейного программирования (П) можно построить соответствующую ей двойственную задачу (D)[cite: 5]. 

### Пример построения
[cite_start]Рассмотрим прямую задачу (П) на максимум[cite: 6]:
$$2x_{1}+3x_{2}\rightarrow max$$
При ограничениях:
1. [cite_start]$4x_{1}+8x_{2}\le12$ [cite: 7]
2. [cite_start]$2x_{1}+x_{2}\le3$ [cite: 8]
3. [cite_start]$3x_{1}+2x_{2}\le4$ [cite: 9]
   [cite_start]$x_{1}\ge0, x_{2}\ge0$ [cite: 10]

[cite_start]Цель состоит в получении минимальной оценки сверху на оптимальное значение целевого функционала[cite: 14, 24]. [cite_start]Для этого используется коническая комбинация (линейная комбинация с неотрицательными коэффициентами $y_i$) основных ограничений[cite: 21, 29].

[cite_start]**Двойственная задача (D) примет вид:** [cite: 37, 38, 39]
$$12y_{1}+3y_{2}+4y_{3}\rightarrow min$$
При ограничениях:
* $4y_{1}+2y_{2}+3y_{3}\ge2$
* $8y_{1}+y_{2}+2y_{3}\ge3$
* $y_{1}\ge0, y_{2}\ge0, y_{3}\ge0$

### Теоремы двойственности
* [cite_start]**Слабая двойственность:** Для любых допустимых планов $x$ и $y$ выполняется $c^{\top}x\le b^{\top}y$[cite: 61, 99].
* [cite_start]**Сильная двойственность:** Оптимальные значения целевых функционалов прямой и двойственной задач совпадают: $c^{\top}x^{*}=b^{\top}y^{*}$[cite: 50, 100, 101].

## 2. Правила построения (Общий вид)

[cite_start]Для построения двойственной задачи к задаче в общем виде используются следующие правила соответствия[cite: 125, 126, 131, 143]:

| [cite_start]Прямая задача ($max$) [cite: 143] | [cite_start]Двойственная задача ($min$) [cite: 143] |
| :--- | :--- |
| Коэффициенты целевой функции $c$ | Правые части ограничений $c$ |
| Правые части ограничений $b$ | Коэффициенты целевой функции $b$ |
| Ограничение типа $\le$ | Переменная $y_i \ge 0$ |
| Ограничение типа $\ge$ | Переменная $y_i \le 0$ |
| Ограничение типа $=$ | Переменная $y_i \in \mathbb{R}$ |
| Переменная $x_i \ge 0$ | Ограничение типа $\ge$ |
| Переменная $x_i \le 0$ | Ограничение типа $\le$ |
| Переменная $x_i \in \mathbb{R}$ | Ограничение типа $=$ |

## 3. Двойственный симплекс-метод

[cite_start]Метод осуществляет перебор базисных допустимых планов двойственной задачи, пока не будет найден план, которому соответствует неотрицательный псевдоплан прямой задачи[cite: 282].

### Основные понятия
* [cite_start]**Базисный план двойственной задачи:** $y^{\top}=c_{B}^{\top}A_{B}^{-1}$[cite: 226].
* [cite_start]**Псевдоплан:** Вектор $x$, где базисные компоненты $x_{B}=A_{B}^{-1}b$, а небазисные $x_{N}=0$[cite: 232, 233, 234].

### [cite_start]Алгоритм [cite: 283-300]
1. [cite_start]**Начало:** Сформировать базисную матрицу $A_B$ и найти $A_B^{-1}$[cite: 285].
2. [cite_start]**План:** Найти текущий двойственный план $y$ и соответствующий псевдоплан $x$[cite: 287, 288].
3. **Проверка:** Если $x \ge 0$, то найден оптимум. [cite_start]Конец[cite: 288].
4. **Вывод из базиса:** Выбрать отрицательную компоненту $x_{j_k} < 0$. [cite_start]Индекс $j_k$ выводится из базиса[cite: 289, 290].
5. [cite_start]**Ввод в базис:** * Вычислить $\mu_j = \Delta y^{\top} A_j$ для всех небазисных $j$, где $\Delta y^{\top}$ — $k$-я строка $A_B^{-1}$[cite: 291, 292].
    * [cite_start]Если все $\mu_j \ge 0$, задача несовместна[cite: 293].
    * Найти $\sigma_0 = \min \{ \frac{c_j - A_j^{\top}y}{\mu_j} \}$ для всех $\mu_j < 0$. [cite_start]Соответствующий индекс $j_0$ вводится в базис[cite: 295, 296, 297].
6. [cite_start]**Итерация:** Обновить множество базисных индексов $B$ и вернуться к шагу 1[cite: 299, 300].

## 4. Пример решения (Пример 2)

**Прямая задача:**
[cite_start]$x_1 + x_2 \rightarrow max$ [cite: 300]
При ограничениях:
$2x_1 + x_2 - x_3 = 3$
$-2x_1 - x_2 - x_4 = -6$
$-x_1 - 2x_2 - x_5 = -6$
[cite_start]$x_i \ge 0$ [cite: 301]

**Результаты итераций:**
* **Итерация 1:** При базисе $B=\{1, 3, 4\}$ получен псевдоплан $x^{\top}=(6, 0, 9, -6, 0)$. [cite_start]Компонента $x_4 = -6$ отрицательна[cite: 309, 310].
* **Итерация 2:** После замены индекса 4 на 2, получен псевдоплан $x^{\top}=(2, 2, 3, 0, 0)$. [cite_start]Поскольку все компоненты неотрицательны, найден оптимальный план[cite: 317, 318].

[cite_start]**Ответ к примеру 3:** $x = (1/4, 1/2, 0, 0, 0)^{\top}$[cite: 323].
