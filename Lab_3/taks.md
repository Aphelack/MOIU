### Пример совместной задачи

\[
x_1 + 2x_2 \to \max
\]

при ограничениях

\[
\begin{cases}
x_1 - x_2 = 0,\\
x_1 \ge 0,\ x_2 \ge 0.
\end{cases}
\]

8. Построить вектор \(\theta \in \mathbb{R}^m\):

   \[
   \theta_i =
   \begin{cases}
   \dfrac{x_{j_i}}{z_i}, & \text{если } z_i > 0,\\[4pt]
   \infty, & \text{если } z_i \le 0,
   \end{cases}
   \]

   где \(j_i\) — \(i\)-й базисный индекс.[file:1]

9. Вычислить \(\theta_0 = \min\limits_{i} \theta_i\).[file:1]  
10. Если \(\theta_0 = \infty\), целевой функционал неограничен сверху, метод завершает работу соответствующим сообщением.[file:1]  
11. Найти индекс \(k\), на котором достигается минимум \(\theta_0\). При множестве минимальных выбрать минимальный по номеру.[file:1]  
12. В наборе \(B\) заменить \(k\)-й индекс на \(j_0\), то есть положить \(j_k = j_0\).[file:1]  
13. Обновить компоненты плана \(x\):

    - \(x_{j_0} = \theta_0\);[file:1]
    - для всех \(i \in \{1, \dots, m\}, i \ne k\):

      \[
      x_{j_i} := x_{j_i} - \theta_0 z_i;
      \]

    - \(x_{j^*} = 0\), где \(j^*\) — заменённый базисный индекс.[file:1]
